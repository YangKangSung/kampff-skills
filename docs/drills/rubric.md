# Drill rubric (self-score 0–100)

Score **after** seeing GOLD. Be harsh on overclaim; generous on thin-corpus humility.

## Weights

| # | Criterion | Pts | How to score |
|---|-----------|----:|--------------|
| 1 | **Distance tag** | 25 | Exact gold tag = 25; adjacent (neutral↔soft-engage) = 15; opposite family (engage vs avoid) = 0 |
| 2 | **Quote discipline** | 20 | ≥2 real quotes from texts = 20; 1 = 10; paraphrase-only / invented = 0 |
| 3 | **L3 stability** | 15 | Correct chronic/mixed/one-off call = 15; vague = 5; wrong chronicity = 0 |
| 4 | **clinical one_line** | 15 | Same *process* as gold (not same words) = 15; trait dump only = 5; diagnosis name as fact = 0 |
| 5 | **ACH rivals** | 10 | Lead + ≥1 weak/fail rival = 10; single H only = 4 |
| 6 | **Overclaim penalty** | 15 | Full 15 if no DSM-as-fact, no mind-read intent, confidence fits N; −5 each violation (floor 0) |

**Total = sum (max 100).**

## Bands

| Score | Band | Next |
|------:|------|------|
| 85–100 | sharp | Next drill or real run |
| 70–84 | solid | Re-read miss criterion only |
| 50–69 | soft | Re-run **same** case cold next day |
| <50 | reset | Re-read [`profiling-craft.md`](../profiling-craft.md) bias traps |

## Distance adjacency map

```text
engage  ↔  neutral  ↔  caution  ↔  avoid
         soft-engage sits between engage and neutral
```

Gold may say `neutral ~ soft-engage` — either tag counts as **exact** if both listed.


## Anti-patterns (auto low score)

- “NPD/사이코패스 확정”  
- No quotes  
- Distance from MBTI alone  
- “설득해서 고쳐야” as default advice  
- Treating satire/news-paste as personality
