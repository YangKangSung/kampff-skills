## Bias traps (kill these first)

| Trap | Symptom | Fix |
|------|---------|-----|
| **Halo / horn** | One good/bad post colors whole dossier | Force 2+ quote families |
| **Fundamental attribution** | Situation → “they are X” | Mark situational vs chronic (L3) |
| **Overclaim diagnosis** | DSM names as fact | `signals consistent with…` + clinical `not_claimed` |
| **Brand flip = personality flip** | Vendor praise→cancel = “unstable” | Same bar, new measurement → L5 note |
| **Thin corpus swagger** | n=8 comments → high confidence | Cap confidence; fewer axes filled |
| **Persuade fantasy** | “How do I win them?” | Distance + engage cost only |
| **Viewer exemption** | Soft on self | Same protocol on `me` |
| **Quote laundering** | Paraphrase as evidence | Paste short quote or `low` |

## Operator checklist (every real or drill run)

1. **Honesty first** (if collect) — triad not “다 긁음”  
2. **Distance first** in TL;DR — then story  
3. **≥2 quotes** for PROBABLE+ claims  
4. **L3 stability** explicit (chronic / mixed / one-off)  
5. **clinical** one_line + distance_bridge (community default)  
6. **ACH** ≥2 rival Hs (lead + fail/weak)  
7. **Cross-check** 3 open prompts — do not fill user’s gut  
8. **Never** medical/legal verdict
